How to Install on Any TV in 2 Minutes

Pick the method easiest for you. No PC or cables needed!

  • 1

    Install Downloader on TV

    On your Android TV / Google TV / Fire TV, open the Play Store or Appstore and search for Downloader by AFTVnews.

  • 2

    Enter Quick Code

    Launch Downloader, enter code 28544 into the URL bar, and click Go. The APK downloads automatically.

  • 3

    Install & Set as Default

    Click Install. When opened, follow the 4-step wizard to clean background apps, paste your Google Photos link, and set TvHome as default!

  • 1

    Download APK on Phone

    Download the Stable APK from this website directly onto your smartphone.

  • 2

    Open "Send Files to TV"

    Ensure both your phone and TV are connected to the same Wi-Fi. Open Send Files to TV on both devices and transfer the APK.

  • 3

    Open & Launch

    On TV, open the file with a TV file manager (like File Commander or TV Bro) and tap Install.

  • 1

    Copy APK to USB Pen Drive

    Download the APK onto your computer or phone and copy it to a FAT32/NTFS formatted USB flash drive.

  • 2

    Plug into TV

    Plug the USB drive into your TV's USB port. Open your TV's native File Manager or Media Player.

  • 3

    Install

    Locate `TvHome.apk` and tap Install. Confirm "Install from unknown sources" if prompted.

  • 1

    Connect via Wireless ADB

    Enable Network Debugging in Developer Options on TV, then run:
    adb connect <tv-ip>:5555

  • 2

    Install via Command Line

    Run: adb install -r app-release.apk
